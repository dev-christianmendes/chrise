# 0004 — PWA em vez de app nativo

**Status:** Aceito · **Data:** 2026-11-09

## Contexto

O usuário principal é o próprio desenvolvedor, que usa o app no celular para lançar gastos e consultar o disponível do mês. O produto precisa ser instalável, abrir em tela cheia e continuar útil sem rede, sem aumentar a manutenção com duas bases de código.

## Decisão

O app é um PWA com `vite-plugin-pwa`: manifest com nome, ícones, `display: standalone`, atalhos e service worker com `autoUpdate`. O build estático da demo é publicado no GitHub Pages; a versão de produção é deployada na Vercel. As leituras do Supabase usam cache `NetworkFirst` com timeout curto, e a navegação cai para `index.html`.

## Consequências

- Instalação pela tela inicial, sem loja, taxa de desenvolvedor ou processo de revisão.
- Um único código React atende desktop e celular.
- O service worker precisa ser invalidado com cuidado a cada deploy; dados sensíveis não ficam no cache além do necessário.
- Recursos nativos (widgets, notificações push no iOS, integração profunda com o sistema) ficam limitados ou exigem trabalho extra.
